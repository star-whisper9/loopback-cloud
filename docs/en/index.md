Welcome to the Loopback Cloud Documentation Center.

Loopback Cloud Documentation is a **community-driven** guide to building real home servers. Here we publish home server tutorials after simple review.

From simple Windows physical machines, to PVE virtualization solutions, to hardware recommendations and hardware maintenance guides, we are committed to creating a **genuinely useful** curated home server documentation.

:::important

Loopback Cloud's documentation comes from **community contributions**. We conduct simple reviews of contributed content, but cannot guarantee documentation quality or control over AI-generated content. You should be aware of this.

When reading documentation on this site, please think carefully about all instructions and passages marked with **Important**, **Warning**, and other emphasis markers. These contents may potentially damage your software and hardware environment. Loopback Cloud is not responsible for any misoperations caused by reading the documentation. Please use your own judgment!

:::

## Navigation

Loopback Cloud provides documentation in both Chinese and English. **Chinese documentation serves as the baseline**, and most English documentation is translated from it. You can switch languages using the button in the top-right corner of the navigation bar.

Currently, we provide two categories of documentation: **Software** and **Hardware**. The top bar allows switching between documentation categories. The left sidebar allows browsing hierarchically organized documentation by category. The right sidebar will display in-page anchor navigation when your device width is sufficient.

Software documentation focuses on **Operating Systems**, **Utility Software**, and **Software Solutions**. Hardware documentation focuses on **Hardware Facility Maintenance**, **Maintenance and Debugging Practical Guides**, and **Hardware Selection and Purchasing**. You can read as needed.
